# Automatic_classification_ArtWorks
The objective of this project is to develop a CNN capable to classify Art work into 2 categories :
- AI-generated: Artworks generated using artificial intelligence models
- Human-created: Artworks created by human artists

In this repository you will find the complete deep learning workflow including : 
- Data Exploration
- Data Preprocessing
- CNN Architecture
- Model Training
- Model Evaluation
- Hyperparameter Tuning
